## Prerequisites

Before installing MiladyOS, ensure you have:

* [NVIDIA drivers](https://www.nvidia.com/download/index.aspx) installed
* [nvidia-container-toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/install-guide.html) configured
* Reboot recommended after driver installation

## Quick Install

The fastest way to get MiladyOS running:

```bash
curl -sSL https://raw.githubusercontent.com/theycallmeloki/MiladyOS/main/install_miladyos.sh | bash
```
