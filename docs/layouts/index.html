A few things before you land

Good questions.

Is this a desktop OS or a server OS?

Both start from the same ISO, with a role selected in the installer. Server and agent roles run the cluster services. Desktop is standalone. The Sway graphical session is in the latest source and is not included in the public {{ $iso.version }} download.

Can I try it in a virtual machine?

Yes. Use an x86_64 VM with its own disposable disk and attach the ISO as boot media. The installer erases its selected target. The ISO guide includes the repository’s QEMU workflow.

Does it need an internet connection?

The public ISO has no embedded MiladyOS container payload. Server and agent setups need network access to fetch it. Locally built ISOs can embed the payload; GPU drivers and other downloads may still need a connection.

Can I keep my current operating system?

The current installer uses the entire selected disk. It does not provide a guided dual-boot setup. Use a VM or a separate disk, and back up anything you want to keep.

Can I upload my configuration here?

Not yet. You can already prepare a local cidata volume for unattended installation. A web builder and a combined personalized ISO are planned. See the current setup instructions.
