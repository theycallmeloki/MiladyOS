## Text-based installer research (ISO) — d-i vs Calamares

Operator: manual Calamares ISO install was rough "because of 3d"; wants a text
installer, ideally for cleaner automated QEMU testing. Asked for searches:
text Calamares, or any upstream Debian text approach.

**Findings (verified from upstream sources, not vibes):**
- **Calamares has NO text/headless/TUI/batch mode.** trixie `calamares 3.3.14-1`
  is Qt6/QML GUI; full CLI = `-h -v -d -D -c -X -T`. Upstream declines headless.
- 3D pain = Qt Quick defaulting to RHI/OpenGL. Fix: `QT_QUICK_BACKEND=software`
  + `LIBGL_ALWAYS_SOFTWARE=1` (+`QT_OPENGL=software`) in `live-installer-xinitrc`.
- **Upstream Debian text path = d-i + live-installer + preseed.** live-build
  flags: `--debian-installer live --debian-installer-gui false`
  `--bootappend-install "console=ttyS0,115200n8"`. Auto-generates "Start
  installer" + Advanced → Text installer → Install/Expert/Automated
  (`auto=true priority=critical`)/Rescue, in both isolinux and GRUB. Preseed at
  `config/includes.installer/preseed.cfg` is repacked into the d-i initrd and
  auto-loaded. Fully headless on serial.
- **live-installer 58 mechanics (source-verified):** mounts
  `/cdrom/live/filesystem.squashfs` and `tar c . | tar x` into `/target` →
  installed node IS the MiladyOS live rootfs (Docker/k3s/firstboot all there);
  purges live-boot/live-config/calamares-settings-debian + update-initramfs.
  GAPS: (1) ISO-fs payload `/cdrom/payload/…` is NOT in the squashfs → not
  copied, needs preseed late_command; (2) no packagechooser → role via
  `milady.role=` cmdline or a TTY prompt.

**Bugs found while tracing:**
- 🔴 `firstboot/ensure-image.sh` looks for `milady-image.tar.zst` but
  build.sh/build-in-container.sh/rolesq stage `miladyos-image.tar.zst` → live
  boots never load the embedded payload, silently fall back to registry pull.
  (git history shows the name drifted.)
- 🟠 `role-detect.sh` interactive prompt is dead under systemd (`[ -t 0 ]` false
  with stdin=/dev/null) → always defaults to agent. Needs a TTY prompt unit.
- 🟡 `MILADYOS_ROLE` set/passed by build.sh but never consumed.

**Wrote:** `ISO/docs/TEXT-INSTALLER.md` — full research, option table
(A: add d-i alongside Calamares + software-render fix, recommended; B: replace
Calamares; C: Calamares-only render fix), concrete change list, preseed skeleton,
sources.

**Next:** operator ruling on A/B/C. Recommend A: land d-i text (automation
unlock) + the software-render fix, then optionally retire Calamares if size
matters. Also fix the ensure-image payload filename + role prompt regardless.

## ✅ Implemented: custom `dialog` text installer (replaces Calamares)

Operator ruling: interactive fun text installer, ASCII art only (no heavy
branding), focused/clean, few steps, everything upfront, disk-focused, hostname
random. Built it (NOT d-i — see docs/TEXT-INSTALLER.md §0 for why).

**New:**
- `ISO/installer/milady-install` — single `dialog` TUI + install engine (~420
  lines). Flow: banner → role → disk → account → (agent token) → confirm →
  gauge install → reboot. Unattended mode: `milady.auto=1 milady.role=…
  milady.disk=… [milady.password=… milady.token=…]` (for QEMU CI).
  Engine: GPT (1MiB bios_grub + 512MiB ESP fat32 + ext4 root), copy live rootfs
  from `filesystem.squashfs`, UUID fstab, node.conf/role-applied cleanup,
  payload → /opt/milady/payload, join-token, operator account, GRUB UEFI+BIOS,
  serial GRUB+kernel console, update-initramfs/update-grub, reboot.
  Disk picker excludes live medium, MILADY_DOCKER scratch, mounted disks,
  zram/loop/ram/dm. Enforces 8GiB min.
- `ISO/installer/ascii-logo.txt` — swappable banner (the only branding knob).
- `ISO/systemd/milady-install.service` — runs installer on `/dev/console`
  (ttyS0 on serial fleet/CI boots, tty0 on VGA), live-only, conflicts gettys.
- `ISO/config/package-lists/miladyos-installer.list.chroot` — dialog, parted,
  gdisk, dosfstools, e2fsprogs, rsync, grub-{pc,efi}-bin, efibootmgr,
  initramfs-tools, kmod.
- `ISO/config/hooks/normal/1400-installer.chroot` — enables the service.

**Removed (gio trash; Calamares GUI retired — no text mode, Qt6/QML 3D pain):**
- `config/package-lists/miladyos-calamares.list.chroot`
- `config/hooks/normal/1400-calamares.chroot`
- `systemd/milady-live-installer.service`, `calamares/live-installer-{session,xinitrc}`
- `ISO/calamares/` modules/branding remain parked (unused) for reference.

**Fixed:**
- `firstboot/ensure-image.sh` payload name mismatch (accepts both
  `miladyos-image.tar.zst` and legacy `milady-image.tar.zst`) — live boots were
  silently falling back to registry pull.
- `firstboot/role-detect.sh` dead prompt: now reads `/dev/console` with a 30s
  timeout, but never prompts on live boots (`/run/live/medium` guard).
- `qemu-install-test.sh`: attaches a throwaway scratch disk as vda so the live
  MILADY_DOCKER store can't grab the install target (vdb); installer is driven
  over the serial socket now (no GUI/sendkey).

**Docs:** `ISO/PLAN.md` D2 + installer layer updated; `ISO/docs/TEXT-INSTALLER.md`
has §0 "what was built" + full d-i research retained.

**Untested:** no docker/ISO build available on this host, so the installer has
only been syntax-checked + parsing-tested. Needs a QEMU install run
(`qemu-install-test.sh out/miladyos-<v>.iso .install-target.qcow2 install`).
